# 可选英文词形线索

`MemoryEngine.recall` 新增 `lexical_policy="inflection"`。默认 `"literal"` 保留原来的检索行为。

```python
results = engine.recall(
    "What books has Elena read?",
    lexical_policy="inflection",
    learning_policy="final",
    read_only=True,
    top_k=5,
)
```

它改善线索发现，例如 research/researching、book/books、read/reading。通过已有词项索引查询有限词形，不扫描整个语料、不建立新的持久索引，也不改变数据库格式。

同组词形只贡献一次命中和权重；文档中的重复词形不会因种类多而获得多份加权。候选列表完整时，文档频率使用各词形索引记录的并集，避免重复计数。若触发常见词保护（语料至少1000条、某词形索引频率超过5000），保留跳过候选列表的预算限制，用各词形索引频率之和、截断到活跃记忆总数，作为该组频率的保守上界。不能把未加载的常见词形当成不存在，也不能只取最大单词频率；多个词形可能出现在不同记录里。此上界可能重复计算重叠或回收记录，因而降低部分有效线索加分；它不保证活跃语料的精确并集频率。原始问题仍用于向量嵌入、时间意图、实体锚点、日志和反馈。词形命中会标记 `English inflection cue (relevance only)`，不是事实确认或额外证据。

每个原始词生成最多32个形式；不存在的形式不会加载记忆。沿用100条词法候选和默认64条语义重排上限，以及既有零命中回退预算。查询包含中文时保留原策略。带数字/连字符的标识符和短词不扩展。缓存区分两个策略；排除、抑制、回收状态和记忆类别过滤仍生效。

英文拼写可能有歧义。这只是有限的规则线索，不是完整词形还原器；不处理不规则动词、语义同义词、派生词、跨语言关系或指代推理。改变候选与权重可能提高部分题目，也可能使其他题目退步，因此先作为显式选项使用，不全局启用。

`read_only=True` 保留所有持久记忆、联想关系和查询日志。需要熟悉度更新时可用既有 `learning_policy="final"`，仅最终返回的原始词法匹配获得一次有限强化；纯词形匹配仍遵守该原始词法门槛。检索相关性不等于真实、有效或回答足够完整。保留既有 `legacy` 学习语义，不将本策略称为新的事实反馈机制。

本轮在固定公开LoCoMo子集上验证的是原始对话证据Top5覆盖，不是生成答案正确率；开发集与首次留出集分开报告。具体结果见E盘第十五批报告。

## 词形分组的稀有度归一化

词形策略将覆盖数量与线索辨识力分开。设查询有 n 个组、候选命中 h 个组、非负 IDF 权重为 w，原重叠分 O 已包含 h。正的查询总权重且 h>0 时，倍率为：

```text
rho = (sum(matched w) / sum(query w)) * (n / h)
scale = min(2, 0.5 + 0.5 * rho)
weighted_overlap = O * scale
```

这等于“命中组平均稀有度 ÷ 查询组平均稀有度”。所有权重相同时倍率为1，不再重复奖励命中数量；所有查询组都命中时也为1。命中全是零权重、但其他查询组有正权重时倍率为0.5。查询总权重为0或没有命中时使用中性倍率1；没有命中本身仍是零重叠。倍率在0.5–2之间，沿用原0.5调节系数及上限，不是新的概率或事实置信度。

先求总权重之比，不对查询平均权重设置任意微小数下限；固定非负权重共同缩放时结果不变。这不意味着改变语料后 IDF 不变，原 IDF 截断、文档频率和词形分组仍生效。此归一化仅作用于 `inflection` 的非中文分组；默认 `literal` 与中文查询保留原有加权。

数学性质不保证实际检索效果提高。第十八批使用提前固定的额外公开对话检查证据覆盖，同时列出历史题的收益和退步；不按这批答案调系数，结果详见E盘报告。
